### 起因
最近有个朋友刚刚入坑了鸣潮，这个哥们比较有钱。一上来就先充了3000块钱人民币（大约6w日元），他抽了4个限定角色，但是歪了4次。

给不太了解这游戏卡池的人解释一下

“米池”：
最早应该是米哈游发明的，每次第一次出限定五星，存在50%的概率为非当期up，也就是常驻角色/
这就是所谓的，歪了。


然后大家说这个游戏存在充值检测的机制。
- 也就是所谓的充值的越多，会越非
- 零氪或者说月卡党相对来说会更欧

有些人说存在账号的差异化，有的人账号欧，有的人账号非

这个项目就是想要证实这两点，或者从模拟的角度来看，是否存在这个事情

1. 存在欧号和非号，号欧了就一直欧，号非了就一直非
2. 有些人氪得越多越非
